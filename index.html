01Overview

Skills are textual recipes that encode proven problem-solving experience for LLM agents. Their value is capped by how well the model reads and follows them, and text-space skill evolution never touches the model itself. ParametricSkills trains a hypernetwork that compiles a textual skill, both its content and how to use it, into a LoRA adapter at test time.

Read the abstract

For LLMs, skills are textual recipes encoding mature problem-solving experience. Despite widespread deployment, their utility is limited by the model's ability to comprehend and follow skill instructions. To address this limitation, we propose ParametricSkills, a framework that parameterizes textual skills at test time, enabling context-free management of the full skill lifecycle. Specifically, we first construct a large-scale and high-quality skill collection, and then synthesize single-turn and multi-turn skill-exploitation trajectories. Using this data, we then train a hypernetwork that parameterizes both the content and the exploitation methodologies of skills by converting textual skills into LoRA adapters. To facilitate the real-world application of our framework, we further align the hypernetwork on complex, long-horizon trajectories collected with OpenCode, enabling the models to operate reliably in realistic interactive workflows with ParametricSkills. Across evaluations, ParametricSkills effectively parameterizes skills, yielding substantial gains in task completion. More notably, as parametric skills accumulate as adapters rather than crowding the context, they open a preliminary but promising path toward continual learning at test time.

02Method

  1. I

    Parametric skill generation

    A frozen text encoder reads the skill document; the hypernetwork maps it to per-layer LoRA factors that condition the frozen base model: W0 + ΔW.

  2. II

    Skill-reconstruction pretraining

    Stage 1 trains the adapter to reconstruct the full skill document, with extra weight on code, procedure, and instruction spans so the details survive compression.

  3. III

    Skill-exploitation fine-tuning

    Stage 2 supervises single- and multi-turn skill use without a harness; Stage 3 aligns on long-horizon OpenCode agent trajectories with tools and feedback.

  4. IV

    Evolution & continual learning

    A verifier accepts or rejects candidate answers and the text skill is revised and recompiled; accepted adapters merge into a global parametric skill by EMA.

05Self-evolution & continual learning

Skills are revised in text space and recompiled into adapters, and only verifier-accepted candidates are kept. For continual learning, each accepted task adapter is normalized and merged into a global parametric skill by an exponential moving average, with no backpropagation at test time.
